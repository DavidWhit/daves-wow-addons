# Dave's Map (`daves_map`) — Architecture & Settled Design Notes

Read this file before modifying `wowaddons/daves_map/` so changes compose cleanly and never regress settled behavior.

## Module Ownership & Layering (`.toc` Load Order)

1. **`Core.lua`**: SavedVariables (`daves_mapDB`, `daves_mapCharDB`), `dataSchema = 4`, `BACKGROUND_STYLES`, `EnforceWindowedOpaqueMap()` (`miniWorldMap = "1"`, `mapFade = "0"`, `questLogOpen = "0"`), `SetAllOptionalLayers()`, audio helper (`ns.Sound`, `ns.WithMutedSound`), quest-log/super-tracking wrappers (`QuestLogCounts`, `ToggleQuestTrack`, `LinkQuestInChat`), strict per-character `IsCharQuestCompleted()`, slash commands (`/dmap`, `/dmap dock`, `/dmap reset`, `/dmap style`, `/dmap options`, `/dmap check [questID]`, `/dmap toggle`, `/dmap zone`, `/dmap calib`, `/dmap seamless`, `/dmap version`).
2. **`Stitch/*.lua`**: Embedded OpenMap `v0.8.10` seamless stitched world map & multi-floor dungeon/raid maps (data/art in companion `daves_map_textures`).
   - `Stitch/WorldMap.lua` (`OnCanvasClick`, `OnPinMouseUp`, Waypoints): Empty-map left-click zooms progressively through `World -> Continent -> Zone -> City -> 1.85x steps -> MaxZoomAt(u, v)`; right-click symmetrically steps out `/ 1.85` when zoomed deep, then `Zone -> Continent -> World`. User waypoint pins sit at `PIN_FRAME_LEVEL_WAYPOINT_LOCATION` and handle `RightButton` via `pin.OnRightClick` (`ClearPin`, plus an `OnCanvasClick` hover guard and `Layer.lua`'s priority-1100 `WaypointLocationPinTemplate` canvas handler when non-stitched) so right-clicking a map pin always removes it without zooming out.
   - `Stitch/Dungeons.lua` (`DockNow`): Guards against `ns.IsQuestMapSuppressed()` so OpenMap's dungeon side panel (Floors/Bosses/Loot) always docks cleanly inside the dungeon view instead of the suppressed Blizzard `QuestMapFrame`.
3. **`Calibrate.lua`**: `C_Map.GetMapRectOnMap` placement, stitched UV bridge (`ns.WorldUV`), progressive zoom-tier LOD fades (`ns.ComputeLodFades`), active zone lookup (`ns.ViewZoneMap`), and waypoints.
4. **`Quests.lua`**: Pure quest domain model — strict per-character completion by exact Forever `questID` (`C_QuestLog.IsQuestFlaggedCompleted`, no title-match false positives, cache reset on `PLAYER_ENTERING_WORLD` / `QUEST_LOG_UPDATE` / `QUEST_TURNED_IN`), `O(1)` Quest Book index (`LogQuestIDForPin`), cached party/raid quest counts & member lookups (`GroupQuestCount`, `GroupQuestMembers`, `GroupQuestCountForPin`, `RefreshGroupQuestCounts` via `C_QuestLog.IsUnitOnQuest`, gated by `db.groupQuestCount` / `ns.ShowGroupQuestCount()` and invalidated on `GROUP_ROSTER_UPDATE` / `UNIT_QUEST_LOG_CHANGED`), sequential chain graph (`ChainFor`, `ChainProgress`, `ResolveActiveChainPin`), live/estimated XP, item display (`Lvl`) & rewards (`ItemDisplay`, `PinRewards`), `ChainWorth`, and dungeon quest context (`DungeonContextForPin`, `IsDungeonQuestPin`).
5. **`Focus.lua`**: Single state owner for tracked/focused quest pins (`ActiveFocusQuest`, `CollectTrackerQuests` covering `focused`, `ready`, `pinned`, `tracking`, and `log` buckets, `UpdateFocus`, `TrackedContains` — with `FindQuestPinsForTracker` fallback and never dropping a player's own tracked quest behind faction filters), tab-driven `Zone`/`Dungeon` reference layers (`SetRefLayer`, `RefreshRefLayerSet` with strict `Base`/`Tracker` guard, `refPinnedMap`, `OnUserMapNavigate`), unified Objective Tracker POI & quest-text click focusing (switching to the Base map layer + `Tracker` tab, drilling straight into `QuestDetails.lua` Quest Text, and flying to target), single-pin selection (`SetFocusedPin`), and map flight (`ShowPinMap`).
6. **`MapChrome.lua`**: Taint-free removal of Blizzard's default Quest Log side panel (`QuestMapFrame` silenced & deferred-hidden without touching `SetUIPanelAttribute`/`WorldMapFrame:SetWidth`), `SidePanelToggle`, portrait `BorderFrame` chrome (with `EnableMouseWheel(false)` so wheel scrolling works seamlessly), and top-right canvas tracking/pin buttons; builds the single unified HUD Edit Mode `DialogBorderTranslucentTemplate` window (`DavesMapWorldChrome`) around `WorldMapFrame` hosting `[ Far-Left 46px Tab Rail | Live World Map + NavBar | Right Content Pane ]` (shifting `TitleCanvasSpacerFrame` & `ScrollContainer` right to `x = 60` via `LayoutUnifiedMapRegion`, keeping `ScrollContainer` parented to `WorldMapFrame`, scaling uniformly via `ApplyUnifiedScale` with combat deferral & live `TOPLEFT` clamp, and exporting `ns.UNIFIED_LAYOUT` / `GetUnifiedContentWidth` / `SetUnifiedContentWidth` / `ResetUnifiedLayout`), overrides `TOGGLEQUESTLOG` (`L`) to `"TOGGLEWORLDMAP"` outside combat (opening `Tracker & Log` when pressed), and exposes Blizzard's Forever map tracking filters (`ns.BLIZZ_MAP_FILTERS`: `questPOI`, `showQuestLevel`, `showQuestDifficultyColor`, `showDungeonEntrancesOnMap`, `trivialQuests`, `contentTrackingFilter`) for Settings.
7. **`Layer.lua`**: Taint-free world map canvas overlay, zoom-independent worldwide tracked/focused quest pins (bypassing `ZOOM_TIERS`, `view.win` window culling, and faction filtering so every quest on the `Tracker` tab stays visible at every zoom), zoom-LOD loading/fading for optional Base POIs & Zone/Dungeon layers, hover hit-testing (`view.hot`), external map-change / user-drag reference-lock release (`OnUserMapNavigate` — skipping `ViewZoneMap` rebuilds while on `Tracker`), and OpenMap dungeon-pin coordination.
8. **`Tooltip.lua`**: Rich map pin tooltips (including rare monster `Potential Known Drops:` from `D.drops[i]` with icons, quality colors, Lvl/slot, and drop %), top-center Zone & Coordinates Banner, and unmapped-quest HUD veil.
9. **`PanelNav.lua` -> `PanelData.lua` -> `PanelRows.lua` -> `QuestDetails.lua` -> `Panel.lua`**:
   - `PanelNav.lua`: Shared sidebar state (`ns.PanelUI` including `detailQuestID`/`detailPin`), UTF-8/color-safe `Shorten`, shared beveled brass pill helpers & hover tooltips (`AddBrassPillSlices`, `CreateGroupCountPill`, `StyleGroupCountPill`, `ShowGroupQuestTooltip`), `< Back` history (`zoneContextLock`, `dungeonZoneLock`, & `detailQuestID`-aware), drill-in `OpenQuestDetails` / `CloseQuestDetails` / `PopRecentTrackerPush`, unified reference context locking, tab switching (`Base` / `Tracker & Log` / `Zone` / `Dungeon`), under-the-hood tracker quest lookup (`FindQuestPinsForTracker`, `OpenTrackerTab`), and origin-frozen search (`searchOriginMap`).
   - `PanelData.lua`: Pure view-model builders for `Base` (optional POI toggles + Map Settings + moved Blizzard Map Tracking & Filters), `Tracker & Log` (`Focused`, `Ready to Turn In`, `Pinned`, `Tracking`, and remaining `Quest Log` quests — including sortable `logquest` rows for quests without QuestieDB pins — with track checkboxes on every in-log quest), `Zone` & `Dungeon` structured sortable 4-column quest grids (`Quest | Starter | Lvl | XP`), inline starter-grouped chains with dedicated `+`/`-` brass pill toggle buttons, compact group quest-count number pills, indented numbered bullet steps, clickable `Starter` navigation links, item rewards, and origin-frozen Search results.
   - `PanelRows.lua`: Clipped variable-height virtualized row pool with full `ResetRow` cleanup, `row.trackBtn` clickable Objective Tracker checkboxes on `Tracker & Log` rows, `logquest` row rendering, `qcols` sortable column header bars, compact `row.groupBadge` brass number pills, Shift-click chat linking when chat is open (preserving Shift-click waypoints when chat is closed), Right-click drill-in Quest Text on in-log quests in `Zone`/`Dungeon`, and item-only hover tooltips on reward rows.
   - `QuestDetails.lua`: Drill-in Quest Text & Details reader mounted inside `Dave's Map`'s content pane (live objectives, completion text, clickable turn-in NPC link, full description, XP/coin/choice items/choice currencies/fixed items/currencies/unlearned spells/title/skill rewards with item-load caching & tooltips, clickable quest chain steps, `< Back` history button, `Track`/`Untrack`, `Link`, `Share`, and `Abandon` with a taint-free HUD Edit Mode `DavesMapAbandonConfirm` dialog).
   - `Panel.lua`: Mouse-transparent container matching `DavesMapWorldChrome` (`EnableMouse(false)` so the middle live World Map & `NavBar` stay 100% interactive) hosting the far-left `46px` skill-icon tab rail (`Base`, `Tracker & Log`, `Zone`, `Dungeon`) and right content pane (`480px` min / `516px` default width, live horizontal bottom-right resize grip persisted in `contentW`, double-click title-bar/grip width reset, dynamic frame-level sync after OpenMap inserts pin levels), Quest Log capacity bar on `Tracker & Log`, dynamic right-edge `MinimalScrollBar` (with `syncingScroll` guard), square beveled brass skill-icon tab buttons, 3-sliced brass pill buttons, borderless gold toolbar icons (Back arrow on left beside Search, plus Find Me, Drop Waypoint with hoisted active-only `PollPinMode` & `OnHide` disarm, and Map Settings gear on right), and style-aware scrims.
10. **`Tracker.lua`**: Collapsible `Ready to Turn In` section below Blizzard's tracker (clicking opens our drill-in Quest Text inside `Dave's Map`), `"Track only my zone's quests"` with consistent per-quest Pin icons (never pinning ready quests), taint-free `UIParent` group quest-count number pills with class-colored member hover tooltips, and unified Objective Tracker quest-text + `...`/`?` focus & drill-in clicks.
11. **`Options.lua`**: Lazy-built two-column `DavesMapStyleOptions` (`Map Settings`: `Size & Look` on left, moved `Map Tracking & Filters` + tracker toggles on right, anchored to `UIParent`), synced `Esc > Options > AddOns` page (including Blizzard tracking proxy settings with accurate client defaults), and re-entrancy-guarded `ns.NotifySetting(key)`.

## Hard Invariants (Do Not Regress)

- **Windowed, Opaque Map & Suppressed Default Quest Log Without Combat Taint:** Enforce `miniWorldMap = "1"`, `mapFade = "0"`, and `questLogOpen = "0"` via `C_CVar.SetCVar` in `ADDON_LOADED`/`PLAYER_LOGIN`, hide `MaximizeMinimizeFrame` & `SidePanelToggle`, silence & deferred-hide `QuestMapFrame` (`C_Timer.After(0, ...)`), and disable `BorderFrame:EnableMouseWheel(false)`. **Never** call `mm:Minimize()`, `WorldMapFrame:Minimize()`, `SetQuestLogPanelShown()`, or `SetUIPanelAttribute()` from addon code (taints `isMaximized` / `UIPanelWindows` and blocks closing the map in combat).
- **Zero `[]` Tofu Glyphs:** Keep all `daves_map` code strings 7-bit ASCII (no `●`, `▸`, `▾`, `•`, `—`, `–`, `…`). Active-layer dots use `Media/dot.tga` textures; `Shorten()` cuts on UTF-8 & color-code boundaries.
- **Tab-Driven Zone & Dungeon Layers (No `ON`/`Hidden`/`Hide Layer` Chrome):** `Zone` and `Dungeon` always follow the player's zone or the zone moved to on the map (showing dungeons whenever the viewed zone has one), while `Base` (internal tab key `"layers"`) and `Tracker` (`"tracker"`) strictly clear `refMode` and return the map to tracked objectives + checked optional POI layers. Every quest listed on the `Tracker` tab (`Focused`, `Ready to Turn In`, `Pinned`, `Tracking` via `ns.CollectTrackerQuests`) ignores zoom levels (`ZOOM_TIERS`), `view.win` bounds culling, and faction checkboxes so tracked quest pins never disappear when zooming out to continent or world views, and `ViewZoneMap()` changes on zoom/pan never disturb the `Tracker` tab. There is no `ON`/`Hidden` tab badge, `Hide Layer`/`Show Layer` bar, or canvas HUD pill.
- **Unified `Zone` & `Dungeon` Sidebar Reference Precedence (`LockRefContext` / `OnUserMapNavigate` / `suspendAutoSwitch`):** Clicking any link in the `Zone` or `Dungeon` tab (quest, chain step, Starter link, reward item, or dungeon floor) locks `zoneContextLock` / `dungeonZoneLock` + `refPinnedMap` + `sidebarDestZone` AND immediately suspends OpenMap's background `autoSwitch` (`stitch.suspendAutoSwitch = true`) **before** the map moves so Blizzard's host map never reloads/flickers behind the scenes (and `Layer.lua` defers `tierMask` rebuilds & `OnLayerChanged` until `settledFlight`). Only navigating from Blizzard's real Quest Log / Objective Tracker (`QuestClicked`, `OnQuestDetails`, `QuestMapFrame_OpenToQuestDetails`) or directly navigating on the World Map (`OnCanvasClick` zone/parent zoom, `FindMe`, manual map drag into a third zone, or non-autoSwitch `WorldMapFrame:SetMapID`) calls `OnUserMapNavigate` to release the lock, re-enable `autoSwitch`, and switch the zone layer.
- **Clean `SetBackground` Alpha Reset:** Always call `bg:SetVertexColor(1, 1, 1, 1)` right after `bg:SetColorTexture(0, 0, 0, a)` so switching from a textured style back to `Dark` doesn't square alpha (`a * a`).
- **Ignore No-Op `EditBox:OnTextChanged` on Resize/Scale:** WoW fires `OnTextChanged(self, false)` on anchored `EditBox` widgets (`ui.search`) whenever their width or scale changes. Keep `ui.lastSearchText` synced in `PanelNav.lua` and short-circuit `ns.RunSearch()` when normalized text hasn't changed so resizing or scaling never clears `ui.detailQuestID` or kicks the player out of Quest Text.
- **Quest Text Click Audio:** Play only `IG_MAINMENU_OPTION_CHECKBOX_ON`; mute Blizzard's page-flip sound inside `ns.WithMutedSound` when opening Quest Details.
