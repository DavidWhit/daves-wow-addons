# Dave's Map (`daves_map`) — Architecture & Settled Design Notes

Read this file before modifying `wowaddons/daves_map/` so changes compose cleanly and never regress settled behavior.

## Module Ownership & Layering (`.toc` Load Order)

1. **`Core.lua`**: SavedVariables (`daves_mapDB`, `daves_mapCharDB`), `dataSchema = 4`, `BACKGROUND_STYLES`, `EnforceWindowedOpaqueMap()` (`miniWorldMap = "1"`, `mapFade = "0"`, `questLogOpen = "0"`), `SetAllOptionalLayers()`, audio helper (`ns.Sound`, `ns.WithMutedSound`), quest-log/super-tracking wrappers (`QuestLogCounts`, `ToggleQuestTrack`, `LinkQuestInChat`), strict per-character `IsCharQuestCompleted()`, slash commands (`/dmap`, `/dmap dock`, `/dmap reset`, `/dmap style`, `/dmap options`, `/dmap check [questID]`, `/dmap toggle`, `/dmap zone`, `/dmap calib`, `/dmap seamless`, `/dmap version`).
2. **`Stitch/*.lua`**: Embedded OpenMap `v0.8.10` seamless stitched world map & multi-floor dungeon/raid maps (data/art in companion `daves_map_textures`).
   - `Stitch/WorldMap.lua` (`OnCanvasClick`, `OnPinMouseUp`, Waypoints): Empty-map left-click zooms progressively through `World -> Continent -> Zone -> City -> 1.85x steps -> MaxZoomAt(u, v)`; right-click symmetrically steps out `/ 1.85` when zoomed deep, then `Zone -> Continent -> World`. User waypoint pins sit at `PIN_FRAME_LEVEL_WAYPOINT_LOCATION` and handle `RightButton` via `pin.OnRightClick` (`ClearPin`, plus an `OnCanvasClick` hover guard and `Layer.lua`'s priority-1100 `WaypointLocationPinTemplate` canvas handler when non-stitched) so right-clicking a map pin always removes it without zooming out.
   - `Stitch/Dungeons.lua` (`DockNow`, `BuildView`, `OpenCurrentInstance`, `bossUI`): Permanently removes OpenMap's floating `view.sideTabs` (`!` and dungeon swirl edge tabs parented to `WorldMapFrame`) since `Dave's Map` suppresses `QuestMapFrame` (`ns.IsQuestMapSuppressed()`) and provides its own right-hand panel; omits the redundant top-right `view.back` button in the dungeon header bar (leaving the optional `Bosses (N)` toggle pill, `X` close, the shared toolbar Back arrow beside Search, right-click, and `Esc`, with zero-overlap responsive header layout via `bossUI.LayoutHeader`); defaults the floating `view.bossPanel` overlay off (`d.dungeonBossList = false` with one-time `bossListDefaultOff` migration in `Stitch/WorldMap.lua`, still toggleable from the header button) and renders boss & rare spawn markers directly on the dungeon map (gold-rimmed `DungeonSkull` badges for guaranteed bosses, silver-cyan `VignetteKillElite` badges for `rare = true` spawns rendered at every possible spawn/patrol spot from `entry.spots`, always-visible compact nameplates parented to `view.page` (`EnableMouse(false)`) and placed via 2D overlap avoidance `bossUI.PlaceTagNonOverlapping` (keeping interactive `pin` button frame levels fixed so hover never bounces `OnLeave`/`OnEnter`), multi-spot simultaneous hover/focus highlighting, and rich tooltips noting rare spawn status, cross-floor spots, and `"Notable Drops:"` preview via `bossUI.AppendBossDrops` with auto-refresh via `mod.RefreshBossTooltip()` on `ITEM_DATA_LOAD_RESULT`); exposes `HasCurrentInstanceMap` / `OpenCurrentInstance` / `HighlightDungeonBoss` / `FocusDungeonBoss` / `OpenDungeonBoss` / `RefreshBossTooltip` / pure side-effect-free `DungeonBossList` & `DungeonBossFloor`.
3. **`Calibrate.lua`**: `C_Map.GetMapRectOnMap` placement, stitched UV bridge (`ns.WorldUV`), progressive zoom-tier LOD fades (`ns.ComputeLodFades`), active zone lookup (`ns.ViewZoneMap`), live instance floor-map & boss interaction wrappers (`HasCurrentInstanceMap`/`OpenCurrentInstanceMap`/`HighlightDungeonBoss`/`FocusDungeonBoss`/`OpenDungeonBoss`/`DungeonBossList`/`DungeonBossFloor`), and waypoints.
4. **`Quests.lua`**: Pure quest domain model — strict per-character completion by exact Forever `questID` (`C_QuestLog.IsQuestFlaggedCompleted`, no title-match false positives, cache reset on `PLAYER_ENTERING_WORLD` / `QUEST_LOG_UPDATE` / `QUEST_TURNED_IN`), `O(1)` Quest Book index (`LogQuestIDForPin`), cached party/raid quest counts & member lookups (`GroupQuestCount`, `GroupQuestMembers`, `GroupQuestCountForPin`, `RefreshGroupQuestCounts` via `C_QuestLog.IsUnitOnQuest`, gated by `db.groupQuestCount` / `ns.ShowGroupQuestCount()` and invalidated on `GROUP_ROSTER_UPDATE` / `UNIT_QUEST_LOG_CHANGED`), sequential chain graph (`ChainFor`, `ChainProgress`, `ResolveActiveChainPin`), live/estimated XP, item display (`Lvl`) & rewards (`ItemDisplay`, `PinRewards`), `ChainWorth`, and dungeon context, live instance detection & boss loot queries (`CurrentPlayerDungeon`, `MatchDungeon`, `FindDungeonPlace`, `DungeonBosses`, `BossDrops`, `FormatDropPct`, `DungeonContextForPin`, `IsDungeonQuestPin`, resolving Classic & Forever `instanceID`s / names via `INSTANCE_ID_TO_KEY`, `D.dungeons`, `D.bossDrops`, and `Places.lua`).
5. **`Focus.lua`**: Single state owner for tracked/focused quest pins (`ActiveFocusQuest`, `CollectTrackerQuests` covering `focused`, `ready`, `pinned`, `tracking`, and `log` buckets, `UpdateFocus`, `TrackedContains` — with `FindQuestPinsForTracker` fallback and never dropping a player's own tracked quest behind faction filters), tab-driven `Zone`/`Dungeon` reference layers (`SetRefLayer`, `RefreshRefLayerSet` with strict `Base`/`Tracker` guard, `refPinnedMap`, `OnUserMapNavigate`), unified Objective Tracker POI & quest-text click focusing (switching to the Base map layer + `Tracker` tab, drilling straight into `QuestDetails.lua` Quest Text, and flying to target), single-pin selection (`SetFocusedPin`), and map flight (`ShowPinMap`).
6. **`MapChrome.lua`**: Taint-free removal of Blizzard's default Quest Log side panel (`QuestMapFrame` silenced & deferred-hidden without touching `SetUIPanelAttribute`/`WorldMapFrame:SetWidth`), `WorldMapFrame.OverscrollBG`, `WorldMapFrame.NavBar`, anonymous `WorldMapFloorNavigationFrame` (`WorldMapFrame.overlayFrames`), `SidePanelToggle`, portrait `BorderFrame` chrome (with `EnableMouseWheel(false)` so wheel scrolling works seamlessly), and top-right canvas tracking/pin buttons; builds the single unified HUD Edit Mode `DialogBorderTranslucentTemplate` window (`DavesMapWorldChrome`) around `WorldMapFrame` with no top `"Dave's Map - "` title band, hosting `[ Left: Map Column (Dropdowns + Full-Height Map Stage) | Vertical Splitter (8px) | Middle: 46px Tab Rail | Right: Content Pane ]` (sizing `TitleCanvasSpacerFrame` & `ScrollContainer` flush inside `mapStage` with `MAP_MAT_PAD = 1`, `460..900` map width and full `322..900` window height persisted in `mapW`/`contentW`/`bodyH` so both stitched OpenMap and cover-fitted non-stitched maps use the full stage edge-to-edge without top/bottom or left/right margins, keeping `ScrollContainer` parented to `WorldMapFrame` without ever calling `WorldMapFrame:SetSize()`, freely movable via taint-free cursor-delta dragging on outer chrome/map borders, empty nav bar, middle tab rail, and right toolbar persisted in `ns.db.windowPos` with full-chrome screen clamping and `UpdateUIPanelPositions`/`UpdateScaleForFitForOpenPanels`/`SynchronizeDisplayState`/`DISPLAY_SIZE_CHANGED`/`UI_SCALE_CHANGED` restore hooks without calling protected `StartMoving()`, scaling uniformly via `ApplyUnifiedScale` with combat deferral, committing resize via `CommitUnifiedMapResize` with `PrepareNonStitchedResize`/`EnsureNonStitchedViewportFit`/`pendingCanvasResize`/`pendingReset`/`pendingPosRestore` combat/hide catch-up, and exporting `ns.UNIFIED_LAYOUT` / `GetUnifiedWindowSize` / `SetUnifiedWindowSize` / `ResetUnifiedLayout(keepPos)` / `AttachWindowDrag`), overrides `TOGGLEQUESTLOG` (`L`) to `"TOGGLEWORLDMAP"` outside combat (opening `Tracker & Log` when pressed), and exposes Blizzard's Forever map tracking filters (`ns.BLIZZ_MAP_FILTERS`: `questPOI`, `showQuestLevel`, `showQuestDifficultyColor`, `showDungeonEntrancesOnMap`, `trivialQuests`, `contentTrackingFilter`) for Settings.
7. **`MapStage.lua`**: Replaces Blizzard's `NavBar` and floor dropdown with a clean 3-slot `WowStyle1DropdownTemplate` navigation bar (`World/Continent`, `Zone`, optional `Subzone/Floor`) matching `daves_map`/`daves_sack` (combat-guarded `NavigateToMap` with same-host-map seamless OpenMap refit, deferred `GenerateMenu()` while a menu is open, and single-floor/orphan map label handling), silences `ScrollContainer.Child.TiledBackground` and `WorldMapFrame.OverscrollBG` (`SetAlpha(0)`), paints a full-bleed subtly zone-tinted map backdrop filling `mapStage` edge-to-edge behind `ScrollContainer` using each map's native `C_Map.GetMapArtBackgroundAtlas(mapID)` (`AdventureMap_TileBg` fallback), `10` muted biome tint palettes, soft top/bottom gradient, 4-corner vignette, and a single subtle `1px` outer stage hairline (with **no** inner frame border around the map), and installs post-`StartStitch()` `ScrollContainer` hooks (`InitNonStitchedViewport`, `PrepareNonStitchedResize`, `EnsureNonStitchedViewportFit`) that scale non-stitched Blizzard maps (such as Zephras Isle, Battlegrounds, Blizzard instance maps, and Seamless-off zones) to edge-to-edge `coverScale = max(vw/aw, vh/ah) * 1.001` before the first draw (both out of combat and in combat, with OpenMap-style `Kept` scale/scroll refusal detection + `PLAYER_REGEN_ENABLED` catch-up and combat pin-passthrough protection), with `1.25x` cursor-anchored wheel zoom up to `4x`, immediate edge-clamped left-drag panning (`baseScale = containScale` whenever viewport aspect differs from art), `SCALING_MODE_LINEAR`, player centering on open, and preserved pan/zoom across window resizes (while `Calibrate.lua` keeps non-stitched zone LOD at `12.0` so townsfolk stay visible and `Focus.lua` pans/zooms smoothly to pins and Find Me on non-stitched maps).

## Hard Invariants (Do Not Regress)

- **Windowed, Opaque Map & Suppressed Default Quest Log Without Combat Taint:** Enforce `miniWorldMap = "1"`, `mapFade = "0"`, and `questLogOpen = "0"` via `C_CVar.SetCVar` in `ADDON_LOADED`/`PLAYER_LOGIN`, hide `MaximizeMinimizeFrame` & `SidePanelToggle`, silence & deferred-hide `QuestMapFrame` (`C_Timer.After(0, ...)`), and disable `BorderFrame:EnableMouseWheel(false)`. **Never** call `mm:Minimize()`, `WorldMapFrame:Minimize()`, `SetQuestLogPanelShown()`, or `SetUIPanelAttribute()` from addon code (taints `isMaximized` / `UIPanelWindows` and blocks closing the map in combat).
- **Zero `[]` Tofu Glyphs:** Keep all `daves_map` code strings 7-bit ASCII (no `●`, `▸`, `▾`, `•`, `—`, `–`, `…`). Active-layer dots use `Media/dot.tga` textures; `Shorten()` cuts on UTF-8 & color-code boundaries.
- **Tab-Driven Zone & Dungeon Layers (No `ON`/`Hidden`/`Hide Layer` Chrome):** `Zone` and `Dungeon` always follow the player's zone or the zone moved to on the map (showing dungeons whenever the viewed zone has one), while `Base` (internal tab key `"layers"`) and `Tracker` (`"tracker"`) strictly clear `refMode` and return the map to tracked objectives + checked optional POI layers. Every quest listed on the `Tracker` tab (`Focused`, `Ready to Turn In`, `Pinned`, `Tracking` via `ns.CollectTrackerQuests`) ignores zoom levels (`ZOOM_TIERS`), `view.win` bounds culling, and faction checkboxes so tracked quest pins never disappear when zooming out to continent or world views, and `ViewZoneMap()` changes on zoom/pan never disturb the `Tracker` tab. There is no `ON`/`Hidden` tab badge, `Hide Layer`/`Show Layer` bar, or canvas HUD pill.
- **Unified `Zone` & `Dungeon` Sidebar Reference Precedence (`LockRefContext` / `OnUserMapNavigate` / `suspendAutoSwitch`):** Clicking any link in the `Zone` or `Dungeon` tab (quest, chain step, Starter link, reward item, or dungeon floor) locks `zoneContextLock` / `dungeonZoneLock` + `refPinnedMap` + `sidebarDestZone` AND immediately suspends OpenMap's background `autoSwitch` (`stitch.suspendAutoSwitch = true`) **before** the map moves so Blizzard's host map never reloads/flickers behind the scenes (and `Layer.lua` defers `tierMask` rebuilds & `OnLayerChanged` until `settledFlight`). Only navigating from Blizzard's real Quest Log / Objective Tracker (`QuestClicked`, `OnQuestDetails`, `QuestMapFrame_OpenToQuestDetails`) or directly navigating on the World Map (`OnCanvasClick` zone/parent zoom, `FindMe`, manual map drag into a third zone, or non-autoSwitch `WorldMapFrame:SetMapID`) calls `OnUserMapNavigate` to release the lock, re-enable `autoSwitch`, and switch the zone layer.
- **Clean `SetBackground` Alpha Reset:** Always call `bg:SetVertexColor(1, 1, 1, 1)` right after `bg:SetColorTexture(0, 0, 0, a)` so switching from a textured style back to `Dark` doesn't square alpha (`a * a`).
- **Ignore No-Op `EditBox:OnTextChanged` on Resize/Scale:** WoW fires `OnTextChanged(self, false)` on anchored `EditBox` widgets (`ui.search`) whenever their width or scale changes. Keep `ui.lastSearchText` synced in `PanelNav.lua` and short-circuit `ns.RunSearch()` when normalized text hasn't changed so resizing or scaling never clears `ui.detailQuestID` or kicks the player out of Quest Text.
- **Quest Text Click Audio:** Play only `IG_MAINMENU_OPTION_CHECKBOX_ON`; mute Blizzard's page-flip sound inside `ns.WithMutedSound` when opening Quest Details.
