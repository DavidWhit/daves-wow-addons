# Dave's Map (`daves_map`) — Architecture & Settled Design Notes

Read this file before modifying `wowaddons/daves_map/` so changes compose cleanly and never regress settled behavior.

## Module Ownership & Layering (`.toc` Load Order)

1. **`Core.lua`**: SavedVariables (`daves_mapDB`, `daves_mapCharDB`), `dataSchema = 4`, `BACKGROUND_STYLES`, `EnforceWindowedOpaqueMap()`, `SetAllOptionalLayers()`, audio helper (`ns.Sound`, `ns.WithMutedSound`), quest-log/super-tracking wrappers, strict per-character `IsCharQuestCompleted()`, slash commands (`/dmap`, `/dmap dock`, `/dmap reset`, `/dmap style`, `/dmap options`, `/dmap check [questID]`, `/dmap toggle`, `/dmap zone`, `/dmap calib`, `/dmap seamless`, `/dmap version`).
2. **`Stitch/*.lua`**: Embedded OpenMap `v0.8.10` seamless stitched world map & multi-floor dungeon/raid maps (data/art in companion `daves_map_textures`).
   - `Stitch/WorldMap.lua` (`OnCanvasClick`, `OnPinMouseUp`, Waypoints): Empty-map left-click zooms progressively through `World -> Continent -> Zone -> City -> 1.85x steps -> MaxZoomAt(u, v)`; right-click symmetrically steps out `/ 1.85` when zoomed deep, then `Zone -> Continent -> World`. User waypoint pins sit at `PIN_FRAME_LEVEL_WAYPOINT_LOCATION` and handle `RightButton` via `pin.OnRightClick` (`ClearPin`, plus an `OnCanvasClick` hover guard and `Layer.lua`'s priority-1100 `WaypointLocationPinTemplate` canvas handler when non-stitched) so right-clicking a map pin always removes it without zooming out.
3. **`Calibrate.lua`**: `C_Map.GetMapRectOnMap` placement, stitched UV bridge (`ns.WorldUV`), progressive zoom-tier LOD fades (`ns.ComputeLodFades`), active zone lookup (`ns.ViewZoneMap`), and waypoints.
4. **`Quests.lua`**: Pure quest domain model — strict per-character completion by exact Forever `questID` (`C_QuestLog.IsQuestFlaggedCompleted`, no title-match false positives, cache reset on `PLAYER_ENTERING_WORLD` / `QUEST_LOG_UPDATE` / `QUEST_TURNED_IN`), `O(1)` Quest Book index (`LogQuestIDForPin`), cached party/raid quest counts & member lookups (`GroupQuestCount`, `GroupQuestMembers`, `GroupQuestCountForPin`, `RefreshGroupQuestCounts` via `C_QuestLog.IsUnitOnQuest`, gated by `db.groupQuestCount` / `ns.ShowGroupQuestCount()` and invalidated on `GROUP_ROSTER_UPDATE` / `UNIT_QUEST_LOG_CHANGED`), sequential chain graph (`ChainFor`, `ChainProgress`, `ResolveActiveChainPin`), live/estimated XP, item display (`Lvl`) & rewards (`ItemDisplay`, `PinRewards`), `ChainWorth`, and dungeon quest context (`DungeonContextForPin`, `IsDungeonQuestPin`).
5. **`Focus.lua`**: Single state owner for tracked/focused quest pins (`ActiveFocusQuest`, `CollectTrackerQuests`, `UpdateFocus`, `TrackedContains` — unifying `Focused`, `Ready to Turn In`, `Pinned`, and `Tracking` across both map pins and the `Tracker` tab, with `FindQuestPinsForTracker` fallback and never dropping a player's own tracked quest behind faction filters), tab-driven `Zone`/`Dungeon` reference layers (`SetRefLayer`, `RefreshRefLayerSet` with strict `Base`/`Tracker` guard, `refPinnedMap`, `OnUserMapNavigate`), unified Objective Tracker POI & quest-text click focusing (switching to the Base map layer + `Tracker` tab + flying to target), single-pin selection (`SetFocusedPin`), side-by-side Quest Text details sync (`SyncQuestDetailsPane`), and map flight (`ShowPinMap`).
6. **`Layer.lua`**: Taint-free world map canvas overlay, zoom-independent worldwide tracked/focused quest pins (bypassing `ZOOM_TIERS`, `view.win` window culling, and faction filtering so every quest on the `Tracker` tab stays visible at every zoom), zoom-LOD loading/fading for optional Base POIs & Zone/Dungeon layers, hover hit-testing (`view.hot`), external map-change / user-drag reference-lock release (`OnUserMapNavigate` — skipping `ViewZoneMap` rebuilds while on `Tracker`), and OpenMap dungeon-pin coordination.
7. **`Tooltip.lua`**: Rich map pin tooltips (including rare monster `Potential Known Drops:` from `D.drops[i]` with icons, quality colors, Lvl/slot, and drop %), top-center Zone & Coordinates Banner, and unmapped-quest HUD veil.
8. **`PanelNav.lua` -> `PanelData.lua` -> `PanelRows.lua` -> `Panel.lua`**:
   - `PanelNav.lua`: Shared sidebar state (`ns.PanelUI`), UTF-8/color-safe `Shorten`, shared beveled brass pill helpers & hover tooltips (`AddBrassPillSlices`, `CreateGroupCountPill`, `StyleGroupCountPill`, `ShowGroupQuestTooltip`), `< Back` history (`zoneContextLock` & `dungeonZoneLock`-aware), unified reference context locking (`LockRefContext`, `ActiveZoneContext`, `ActiveDungeonZone`, `SwitchZoneContext`, `SwitchDungeonZone`, `ClearRefContext`), tab switching (`Base` / `Tracker` / `Zone` / `Dungeon`), under-the-hood tracker quest lookup (`FindQuestPinsForTracker`, `OpenTrackerTab`), and origin-frozen search (`searchOriginMap`).
   - `PanelData.lua`: Pure view-model builders for `Base` (internal key `"layers"`, optional POI toggles defaulting ON with right-side header checkboxes + embedded Map Settings), `Tracker` (`Focused`, `Ready to Turn In`, `Pinned`, `Tracking` quests pulled from `daves_map_data` on the Base map layer), `Zone` & `Dungeon` structured sortable 4-column quest grids (`Quest | Starter | Lvl | XP` via `ToggleQuestSort`, deterministic tie-breaking with no volatile XP shifts), inline starter-grouped chains with dedicated `+`/`-` brass pill toggle buttons, compact group quest-count number pills while grouped (`groupCount`, `groupQuestID`), indented numbered bullet steps (`1.`, `2.`, ...), clickable `Starter` navigation links, item rewards shown at the bottom when collapsed or under their granting step when expanded, and origin-frozen Search results.
   - `PanelRows.lua`: Clipped variable-height virtualized row pool with full `ResetRow` cleanup, `qcols` sortable column header bars, compact `row.groupBadge` brass number pills beside quest/step titles while in a group (hovering the pill shows class-colored group member names; clicking still activates the row), and item-only hover tooltips on quest/grid rows (reward items only).
   - `Panel.lua`: Movable & resizable (`min width 588px`, `min height 380px`, slim `46px` skill-icon tab rail, `SetResizeBounds`, persisted in `panelPos`/`panelW`/`panelH`) `DialogBorderTranslucentTemplate` window matching `daves_sack` that always opens and closes with `WorldMapFrame` (double-click title bar / `Dock to Map (Reset Size)` / `/dmap dock` snaps back flush beside the map), dynamic right-edge `MinimalScrollBar` (with `syncingScroll` guard), square beveled brass skill-icon tab buttons (`Media/slot.tga`, `tab_base.tga`, `tab_tracker.tga`, `tab_zone.tga`, `tab_dungeon.tga`, `back.tga`), 3-sliced beveled brass pill buttons (`Media/pill.tga`, `plus.tga`, `minus.tga`), borderless gold toolbar icons (`findme.tga`, `waypoint.tga`, `gear.tga`), and style-aware scrims.
9. **`Tracker.lua`**: Collapsible `Ready to Turn In` section below Blizzard's tracker (no custom quest-row tooltips), `"Track only my zone's quests"` with consistent per-quest Pin icons (including ready/delivery quests and focused-quest precedence), taint-free `UIParent` group quest-count number pills (`groupBadges` + `Ready to Turn In` row pills) matching the brass step-pill style while in a party or raid with hover tooltips listing class-colored group member names (auto-anchored left/right of screen edge and live-refreshed on group quest updates), and unified quest-text + `...`/`?` focus clicks.
10. **`Options.lua`**: Lazy-built `DavesMapStyleOptions` HUD Edit Mode dialog (sliders, `WowStyle1DropdownTemplate`, `Dock to Map (Reset Size)`, anchored to `UIParent` so scale drags never drift), synced `Esc > Options > AddOns` page, and re-entrancy-guarded `ns.NotifySetting(key)`.

## Hard Invariants (Do Not Regress)

- **Windowed & Opaque Map Without Combat Taint:** Enforce `miniWorldMap = "1"` and `mapFade = "0"` via `C_CVar.SetCVar` in `ADDON_LOADED`/`PLAYER_LOGIN` and hide `MaximizeMinimizeFrame`. **Never** call `mm:Minimize()` or `WorldMapFrame:Minimize()` from addon code (taints `isMaximized` and blocks closing the map in combat).
- **Zero `[]` Tofu Glyphs:** Keep all `daves_map` code strings 7-bit ASCII (no `●`, `▸`, `▾`, `•`, `—`, `–`, `…`). Active-layer dots use `Media/dot.tga` textures; `Shorten()` cuts on UTF-8 & color-code boundaries.
- **Tab-Driven Zone & Dungeon Layers (No `ON`/`Hidden`/`Hide Layer` Chrome):** `Zone` and `Dungeon` always follow the player's zone or the zone moved to on the map (showing dungeons whenever the viewed zone has one), while `Base` (internal tab key `"layers"`) and `Tracker` (`"tracker"`) strictly clear `refMode` and return the map to tracked objectives + checked optional POI layers. Every quest listed on the `Tracker` tab (`Focused`, `Ready to Turn In`, `Pinned`, `Tracking` via `ns.CollectTrackerQuests`) ignores zoom levels (`ZOOM_TIERS`), `view.win` bounds culling, and faction checkboxes so tracked quest pins never disappear when zooming out to continent or world views, and `ViewZoneMap()` changes on zoom/pan never disturb the `Tracker` tab. There is no `ON`/`Hidden` tab badge, `Hide Layer`/`Show Layer` bar, or canvas HUD pill.
- **Unified `Zone` & `Dungeon` Sidebar Reference Precedence (`LockRefContext` / `OnUserMapNavigate` / `suspendAutoSwitch`):** Clicking any link in the `Zone` or `Dungeon` tab (quest, chain step, Starter link, reward item, or dungeon floor) locks `zoneContextLock` / `dungeonZoneLock` + `refPinnedMap` + `sidebarDestZone` AND immediately suspends OpenMap's background `autoSwitch` (`stitch.suspendAutoSwitch = true`) **before** the map moves so Blizzard's host map never reloads/flickers behind the scenes (and `Layer.lua` defers `tierMask` rebuilds & `OnLayerChanged` until `settledFlight`). Only navigating from Blizzard's real Quest Log / Objective Tracker (`QuestClicked`, `OnQuestDetails`, `QuestMapFrame_OpenToQuestDetails`) or directly navigating on the World Map (`OnCanvasClick` zone/parent zoom, `FindMe`, manual map drag into a third zone, or non-autoSwitch `WorldMapFrame:SetMapID`) calls `OnUserMapNavigate` to release the lock, re-enable `autoSwitch`, and switch the zone layer.
- **Clean `SetBackground` Alpha Reset:** Always call `bg:SetVertexColor(1, 1, 1, 1)` right after `bg:SetColorTexture(0, 0, 0, a)` so switching from a textured style back to `Dark` doesn't square alpha (`a * a`).
- **Quest Text Click Audio:** Play only `IG_MAINMENU_OPTION_CHECKBOX_ON`; mute Blizzard's page-flip sound inside `ns.WithMutedSound` when opening Quest Details.
